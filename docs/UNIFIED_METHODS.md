# 统一平台数值方法

## 模型与单位

AnalysisCase 的 schema_version 为 3。CAD 版本由源文件 SHA-256 标识，选区包含组件身份。长度、力、应力、能量使用 m、N、Pa、J；温度字段用 °C，温差使用 K。应力统一为 xx、yy、zz、xy、xz、yz，旧热平台在适配层转换。

C3D10 保留接触两侧独立节点。温度采用同一网格上的二阶标量形函数、一致质量矩阵、27 点体积分。界面使用二次三角形积分及曲面投影。热理想连接与机械粘结分别配置。

HDF5 保存拓扑、组件、时间、位移、原始体积分点应力／应变、温度、梯度、热流、原生接触积分点记录、接触面积及运动参考节点。云图为独立显示投影。热反馈采用明确记录的从面平均接触压力；峰值使用原生接触积分点压力。

## 高周疲劳

线性无接触工况可叠加单位载荷应力场。比例应力历史经主应力符号确定等效应力正负，使用雨流计数。Goodman 只修正拉伸均值，Miner 损伤 D=Σ n/N。S-N 在对数坐标插值，高于曲线数据范围不外推；只有明确给出疲劳极限时才报告低于该极限。

Findley 在候选平面内计算剪切路径的最小包围圆半径 τa，加上 kσn,max。平面数量可配置，寿命需要平面、网格和步长核对。常值应力不计疲劳循环。缺少屈服强度、超过弹性范围、缺少适用曲线或首尾应力未闭合时停止该点寿命评估。

每段 Findley 输入表示一个完整基本周期，cycles_per_history 必须为 1；分级比例谱可使用 S-N 路径的循环基数。材料卡给出适用温度范围时，疲劳评估同时核对工况的初始温度（等温疲劳假设），超出范围只保留应力结果。

接触疲劳使用材料随体应力，自由从动轴采用求解得到的实际转角。曲线须标记 rolling_contact 并注明接触条件来源。演示合成曲线只验证流程，不证明实际轴承寿命。寿命的萌生或失效定义来自输入曲线。

## 周期接触与磨损

CalculiX 2.23 的 C3D10 面对面接触在非线性增量内重匹配，可配置法向罚刚度与库仑摩擦。初始间隙／过盈须存在于 CAD，不使用自动调整节点。运动增量与请求的局部网格尺度进行校验。

CF 输出提供真实积分接触面积及合力。热映射和磨损映射在当前形状重建。滑移由当前接触位置的材料速度差计算，剔除刚性滚动导致的虚假位移差与可逆切向罚弹簧位移。Archard 增量 dh=k p ds/H；零滑移为零磨损，纯滚动仍可能有疲劳循环。

循环块累积磨损后使从表面后退，通过内部谐和移动保持节点身份，再求解接触。表面更新检查 Jacobian 和最大允许磨损量，不通过即停止。较大磨损重网格、润滑膜不在此范围。

多磨损块逐材料点累积 Miner 损伤，保存各块状态；任一块未能评估的点不会因后续块成功而被当作已知零损伤。寿命及指定循环损伤以最后已计算块的几何保持不变为条件，不代表后续持续磨损的寿命外推。已模拟循环总数、累计损伤及其危险位置单独保存。

磨损几何更新由周期接触研究执行。瞬态热结构研究保留摩擦接触历史，但不同时演变磨损几何；对此启用磨损标志会在提交前被拒绝。

## 双向耦合

每个物理时间步从上个已收敛状态开始，解热场、热膨胀及机械接触，再根据压力／间隙更新传热。闭合热导从显式压力／温度表插值；张开间隙使用给定空气导热率、间距和截断间隙。缺少传热参数时拒绝配置。

默认松弛 0.5，最多 30 次；温度变化 ≤0.01 K、相对位移 ≤10⁻⁴、相对界面热流 ≤10⁻³ 后再检查最终反馈。瞬态失败最多六次减半时间步，失败时保留诊断及最后收敛状态。机械试算读取上一已提交状态的 CalculiX 原生重启动文件，各自在独立副本中求解，只有收敛后的状态可作为下一物理步起点。网格、材料、连接及重启动文件均校验身份，避免重复累积摩擦历史或从错误模型续算。没有压力反馈的理想连接明确标记为单向三角系统。

保存最终热求解的温度场及对应能量平衡。该温度与最后机械子问题使用的温度差记录为 mechanical_temperature_consistency_K，必须不超过配置的耦合温度容差。命名选区在提交时解析为固定面集合，之后改名不会改变已提交快照。

热平衡核对净热流、蓄热和指定温度反力；机械平衡包括支撑、载荷及刚性轴孔参考力／力矩。每个已收敛物理时间步都记录平衡，包括未输出动画帧的时间步；任何超限项都会使最终状态标记为未完全通过。默认相对误差上限 1%。罚刚度、曲面投影和时间离散仍需独立收敛验证。

## 记录与资源

提交生成不可变快照及 SHA-256。取消终止进程树，保存完整阶段；恢复创建新记录，只复用输入一致且原始文件校验通过的完整阶段。后处理复用同样创建新记录，拒绝改变原始物理问题。

默认一个重型作业、CPU 六线程。显式检查自由度、内存估计和磁盘空间，不自动粗化或降低载荷。内存估计不是测量峰值。

解析导热、热应力、Hertz 接触、恒压磨损用于数值验证；电机用于完整流程。只有具备对应网格和步长证据的具体工况才可标记收敛通过。尖角、理想约束奇异峰值不可作为已验证寿命依据。

独立复算的验证记录保存在 verification.json，绑定原工况、摘要和原始场校验值。报告与界面可显示其检查范围，且不把独立局部网格验证误写为已启用全局自动加密。改变结果身份后，旧验证记录不再有效。

接触输入与增量行为参照 [CalculiX 2.23 官方手册](https://www.dhondt.de/ccx_2.23.pdf)。保留的旧热 GPU 接口在统一 Windows 安装中使用原生 cuDSS 适配器；旧 CuPy 路径仍保留源码，本环境未安装 CuPy，其两项专用测试列为跳过。
