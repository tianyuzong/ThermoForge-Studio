### 失败与兼容性

| 场景 | 验证方式与结果 |
|---|---|
| 欠约束、矛盾约束 | 真实网格约束校验拒绝 |
| 选面歧义 | 注入歧义规划响应，候选面严格绑定真实几何证据；浏览器支持点击高亮 |
| 超资源 | 提交过细网格，资源预检失败；任务与原载荷/网格配置保留 |
| CLI 超时 | 启动实际 CLI 并设置极短超时，触发超时及进程清理 |
| 解释失败 | 注入超时、错误数字和非法反馈；最多三轮，已完成结果和 PDF 保留 |
| 取消 | 规划中、排队中、真实 CPU 工作进程运行中取消通过 |
| 并发重复提交 | 多个并发同一 request_id 只生成一个任务 |
| 服务中断 | 实际在生成网格阶段停止服务并重启；原任务/作业标记 interrupted，配置文件保留 |
| 旧工况 | 版本 1 按既有默认值读取，无新请求时行为兼容 |
| 旧结果 | 去除 v2 专用数据集的历史格式 HDF5 能派生新增字段，查询前后文件逐字节一致 |

真实服务中断记录在 `.runtime/acceptance-restart.json`。该验收项目中的“已中断”状态是主动测试结果。
