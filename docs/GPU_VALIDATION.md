# GPU 接入验证记录

本文为 **0.2 单材料版本的历史验证**。后续组件与齿轮功能分别见[组件工作台](COMPONENT_WORKBENCH.md)和[齿轮接触](GEAR_CONTACT.md)，不将下列加速比外推为新版本或任意工况的性能保证。

验证日期：2026-09-21。功能、数值和两档计算性能目标通过；指定的 Nsight Systems 追踪因 Windows 管理员权限限制未生成，已用独立 CUPTI 内核活动记录完成实际 GPU 执行验证。

## 运行环境与实现

Windows 11 / i5-12400（6 个物理核心）/ 64 GB RAM / RTX 3090 Ti（24,564 MiB）/ 驱动 591.86 / CUDA Toolkit 12.6 / cuDSS 0.8.0.10 / Python 3.14.6。

GPU 使用原生 CUDA/NVRTC 适配层，C3D10 FP64 刚度组装、分解、回代与结果恢复均有真实 CUDA 核执行。CPU 基线为官方 CalculiX 2.23，基准设 STRENGTH_CPU_THREADS=6；普通 CPU 配置可另外调整线程数。

CuPy 14.2.0 的 CUB 扩展被本机 Smart App Control 阻止，因此运行路径改用原生 NVIDIA 库；没有关闭系统安全策略。可选 cuDSS VCOMP 层与 Gmsh 的运行时冲突，实际采用默认 CPU 符号分析，GPU 数值求解不变。

原验收解析解阈值继续通过：拉杆 ≤1%，收敛悬臂梁位移及指定截面应力 ≤3%，力与力矩平衡 ≤1e-4。

## 同网格性能

| 实际自由度 | CPU 六核中位数 | GPU 中位数 | 加速比 |

| 479,001 | 46.952 s | 7.388 s | 6.36× |
| 984,759 | 119.044 s | 20.893 s | 5.70× |

两档均预热后测量三次，GPU 每次重新分解，无缓存偷换；另测分解复用。完全相同的网格、节点载荷、约束与原始结果字段，网格 SHA-256、逐次耗时、检查和执行参数见 [GPU_BENCHMARK.json](GPU_BENCHMARK.json)。

计时包含组装、传输、符号分析、分解、回代及原始场恢复；CPU 包含 INP/DAT 输入输出转换。网格生成和报告不计入上述加速比，不能将其称为整个 Agent 工作流加速比。GPU 的首次启动和编译时间单列；两档同网格位移最大相对 L2 差异 1.576e-07，应力最大相对 L2 差异 1.414e-07。

## 实际 GPU 执行证据

NVIDIA CUPTI Activity API 记录 **3,606 次核执行、82 种核、0 丢失记录**。其中包括 gradients、assemble、recover 以及 cuDSS GEMM、分解、回代等核，全部有有效 GPU 起止时间和设备/上下文编号。

- [原始活动记录](GPU_KERNEL_TRACE.json)
- [逐核汇总 CSV](GPU_KERNEL_SUMMARY.csv)
- 复现：`python scripts/trace_gpu_activity.py`，先运行性能脚本准备固定网格。采集仅作用于本进程，不使用系统 ETW、设备性能计数器或管理员权限。

这不是 Nsight 报告。Nsight Systems 2024.4.2 在普通权限下返回 `ReflexStatsTraceLoggingProvider provider requires administrator privileges`；其官方 Windows CLI [要求管理员权限](https://docs.nvidia.com/nsight-systems/UserGuide/)。保留 `scripts/profile-gpu.ps1` 供有管理员权限时生成 .nsys-rep。本次未更改权限或策略，不能宣称该指定工具的验收项已通过。

## 真实 Agent 自动闭环

Codex CLI 真实调用任务 `9adae8fef5fa4032a8161d78c4b636f4`，由自然语言直接生成并执行两个 GPU 工况，无人工确认。采用 38,508 节点、22,929 个 C3D10 单元，同一网格；第二工况复用分解。

| 工况 | 最大等效应力 | 最大位移 | 屈服安全系数 | 计算阶段 | 完整计算作业 |
|---|---:|---:|---:|---:|---:|

| 顶面向下 1500 N | 104.1852 MPa | 0.0324436 mm | 2.2556 | 0.162 s（复用） | 5.521 s |
