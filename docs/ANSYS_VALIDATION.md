# 与 Ansys 的数值对照：验收约定与当前缺口

当前状态：**尚未完成同条件 Ansys Mechanical / MAPDL 数值对照**。CPU/GPU 弹性场一致性、力学平衡和图文报告不能替代这项验收。本机常见安装目录与环境变量中未发现可调用的 Ansys；没有绑定同模型的 Ansys 参考结果，也没有尝试购买、下载或绕过许可证。

## 对照必须控制的条件

- 几何、单位、组件编号、材料、实际接触位置及初始间隙一致。
- 第一轮使用同一二次四面体网格、相同边界与一致节点载荷，隔离求解实现差异；后续再比较各自收敛网格的工程结果。
- 明确小变形/几何非线性、摩擦、接触法向更新、轴孔/轴承约束、输入与输出扭矩、接触离散和收敛条件。
- 位移、反力使用同一坐标和参考原点；应力分量顺序转换后，按物理位置比较。原始积分点、外推单元节点、跨单元平均节点结果不得混用。
- 保存软件版本、输入文件、网格哈希、求解日志及完整导出数据，不能仅使用截图或某个最大值作基线。

本平台 C3D10 线弹性单元与 Ansys SOLID187 都是二次十节点四面体，后者刚度采用四点积分；这提供了建立受控线弹性比较的基础，但**不是未经对照的等价声明**。依据：[SOLID187 理论](https://ansyshelp.ansys.com/public/Views/Secured/corp/v242/en/ans_thry/thy_el187.html)、[SOLID187 元素说明](https://ansyshelp.ansys.com/public/Views/Secured/corp/v252/en/ans_elem/Hlp_E_SOLID187.html)。

## 建议的工程验收目标

以下是待项目方采用和验证的目标，**不是已测得的精度**：

| 项目 | 对照方法 | 建议目标 |
|---|---|---|
| 线弹性位移 | 同网格节点向量相对 L2 差异，同时检查最大位移 | ≤1% |
| 应力场 | 同口径、对应位置的应力分量相对 L2 差异 | ≤3% |
| 齿根局部应力 | 先指定区域/截面、应力定义与独立收敛 | ≤5% |
| 轴端反力与扭矩 | 相同参考原点，合力与合力矩比较 | ≤1% |
| 接触压力与接触面积 | 同接触设置并独立收敛；比较分布、面积、积分力及峰值 | 收敛峰值与面积差异 ≤5% |
| 平衡 | 各自检查整体力、力矩和接触传力残差 | 相对残差 ≤1e-4 |

接近零的量需为每个物理量预先给定有单位的绝对容差，不能只计算相对误差。固定尖角或刚性边缘的奇异峰值不能通过一个百分比容差判定收敛，应改用有物理意义的指定区域指标。

## 三齿轮当前还差什么

1. 当前仅为无摩擦、小滑移、固定法向接触；用户示例的摩擦系数 0.15、增广拉格朗日和完整啮合周期未实现，不能混为相同物理模型。
2. 刚性轴接口不等同于有实际柔度的轴承支撑，必须在双方统一这些边界条件。
3. 当前尚未完成 Hertz 接触基准、接触网格收敛、齿根指定区域收敛。
4. 齿根弯曲强度需定义真实选区、截面/方向、提取方法、材料许用值，不能以 von Mises 峰值代替。
5. 若要评价点蚀、疲劳、高速冲击或运行干涉，需要相应的寿命、载荷谱、动力学或运动学分析。

Ansys 的官方接触结果检查同样要求核对压力、穿透、接触状态、滑移和收敛，并通过关键界面网格加密检查分布：[Contact results review](https://ansyshelp.ansys.com/public/Views/Secured/corp/v261/en/wb_sim/ds_contact_reviewResults.html)、[Contact workflow](https://ansyshelp.ansys.com/public/Views/Secured/corp/v261/en/wb_sim/ch09s06s02.html)。

当前报告中的“Ansys 同条件对照：尚未验证”是明确的验收缺口。必须取得实际参考输入/结果并完成对照后，才能改变这一状态。
