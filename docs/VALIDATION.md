## 自动化验证

共 **22 项测试已通过**：15 项基础/真实求解测试；7 项任务与连接可靠性测试。后续修正后定向重跑了相关测试。另将悬臂梁测试升级为实际三档网格后重新通过。存在两条上游 TestClient 弃用提示，无计算失败。

| 类别 | 实际验证 |
|---|---|
| 自然语言闭环 | 明确指令直接产生两个真实支架结果和 PDF，无二次确认 |
| 追问 | 缺少载荷时停在 needs_input；补充后自动续算 |

| 取消 | 排队取消与规划中取消均不启动新求解 |
| 恢复 | 服务恢复将非终态任务标为 interrupted，不自动重跑 |

| 选区 | 候选高亮绑定真实面 ID；空选区、无方向选区拒绝 |
| 几何 | STEP 支架四孔；STL 单位、封闭性、二次网格与压力守恒 |
| 物理 | 拉杆、给定位移、自重杆、悬臂梁、约束节点压力反力扣除 |
| 约束 | 欠约束和冲突位移拒绝；未约束方向的位移不能假装有效激励 |

## 数值结果

机器可读数据：`examples/validation-metrics.json`。

| 验证项 | 测得值 | 验收阈值 |
|---|---:|---:|
| 拉杆轴向位移相对误差 | 0.000005% | ≤1% |
| 拉杆应力相对误差 | 小于 10⁻⁹% | ≤1% |
| 悬臂梁端部竖向位移相对误差 | 0.565656% | ≤3% |
| 悬臂梁中段 σxx 的相对 RMS 误差 | 0.192961% | ≤3% |
| 悬臂梁最后两档最大位移变化 | 0.066283% | ≤2% |
| 本次数值回归最大力平衡相对残差 | 1.046 × 10⁻⁸ | ≤10⁻⁴ |
| 本次数值回归最大力矩平衡相对残差 | 1.931 × 10⁻⁸ | ≤10⁻⁴ |

拉杆 L=100 mm，10×10 mm 截面，F=1000 N，E=210 GPa；以分量对称边界允许自由泊松收缩，解析位移 FL/EA。

悬臂梁 L=200 mm，20×10 mm 截面，端部竖向 F=1 N，E=210 GPa；网格目标 9、6、4 mm。位移参考 Euler–Bernoulli FL³/(3EI)。截面应力比较取 x=80–120 mm 区间、距中性轴大于 2 mm 的积分点，与 Mz/I 的 σxx 比较，远离固定端奇异峰值。该指标不是全局 von Mises 峰值误差。

## 实际 Codex CLI 验证

从工作台页面发送一条中文指令，CLI 沿用用户已配置模型，读取真实支架证据后生成四个工况。宿主自动执行并生成四份中文 PDF，无人工确认：

1. 顶面向下 1000 N。
2. 顶面向下 1500 N。
3. 顶面沿全局 +Y 方向 300 N。
4. 顶面同时施加向下 1000 N 与 +Y 方向 300 N。

实际记录保存在 `examples/agent-plan.json`、`cases.json`、`demonstration-metrics.json` 和 `case-*`。四个工况网格文件哈希完全相同；1000→1500 N 应力严格按 1.5 倍比例变化（受结果输出精度影响）。所有工况通过力和力矩检查。

已在真实浏览器中检查项目加载、材料与命名选区、Agent 提交、后台持续执行、刷新后恢复记录、结果云图、峰值/剖切控件以及硬件检测面板。TypeScript 和 Vite 生产构建成功。中文 PDF 经 Poppler 渲染逐页检查，无乱码、表格截断或重叠。
