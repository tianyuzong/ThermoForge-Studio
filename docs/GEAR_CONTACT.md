# 三齿轮静态强度教学

该模式为实验性的无摩擦、小滑移、固定法向接触，不是已验证的通用齿轮寿命分析器。真实 C3D10 有限元刚度、弹性求解与积分点应力恢复运行在 NVIDIA GPU；接触搜索及小型互补问题在 CPU 上求解。CAD 未平移、未焊接，各组件有独立位移自由度。

## 本例条件

- 用户明确授权采用教学假设。原始 STEP 保留在本机，三组件分别指定材料。
- 假设钢材 E=210 GPa、ν=0.3、密度 7850 kg/m³、屈服 355 MPa；这些不是实物牌号证明。
- 三个齿轮分别绑定自身轴孔和轴心，面编号来自具体 CAD，不可直接复用于其他模型。本仓库不包含该用户模型、几何证据或会话快照；使用时须自行导入并保存明确的轴孔与接触设置。
- 所有轴平行全局 Z，轴心平移和倾斜锁定，孔壁与刚性轴耦合。小齿轮输入 +Z 右手方向轴端扭矩；中间轮绕 Z 自由；大齿轮输出轴转角锁止。输出阻力矩由求解给出。
- 计算 5、10、15 N·m 三种工况。无重力、摩擦、冲击、塑性或疲劳。原始 CAD 两处最小间隙约0.00720449和0.00471437 mm，无体积干涉。
- 全局目标尺寸5 mm，Gmsh曲率及CAD边界控制保留。249,476节点、144,905 C3D10单元、748,428自由度。未完成网格收敛。首轮3 mm试网格因超过120万自由度被明确停止，随后人工选择5 mm教学网格；不是自动粗化。

## 可复核的计算方法

位移表示为 `u = ue + R theta`。`ue` 在轴孔处为零，`R theta` 是每个未锁止齿轮绕真实轴心的小刚体转角。此分解是刚性轴接口的运动学条件，并不把自由轴转角固定。在线性小变形范围，刚体项不产生应变。

从面每个T6面分成4个子三角形，取其内部积分点，并投影至主面的真实二次插值曲面。双方均用二次形函数，法向力作功共轭地映射到节点。只保留相向且在搜索距离内的曲面，保留初始间隙。不是二次单元角节点到面的点接触算法。该离散仍需接触压力和网格收敛验证。

令间隙 `g = g0 + B u`，压缩接触力 `p >= 0`，则节点接触力 `B^T p`。用 GPU 分解轴孔参考问题的 `Kff`，多右端求解得到柔度 `C = Bf Kff^-1 Bf^T`。定义 `A = B R` 后，CPU主动集求解：

```
minimize 0.5 p^T C p + g0^T p
subject to A^T p = -T, p >= 0
```

解的乘子给出轴转角，检查 `g>=0`、`p>=0`、`p*g=0`、各自由轴扭矩平衡。无弱弹簧、罚刚度或求解失败后的载荷修改。最终回到GPU恢复完整弹性应力场，并独立检查自由度内力残差与整体力/力矩平衡。转角超过0.01 rad或相对切向位移超过一半搜索距离时停止，不冒充有限滑移求解。

同一任务的同网格、材料、轴孔、接触设置可复用GPU分解及凝聚柔度；改扭矩仍独立求接触主动集。取消或任务结束时随工作进程释放上下文。

## 结果的含义

- 最大等效应力、安全系数：来自体单元四个原始积分点的von Mises应力及各组件假设屈服强度。
- 应力云图：积分点外推后体积加权节点场，与强度峰值可能不同。
- 总位移：含弹性变形和闭合初始齿隙的轴端转角。弹性变形单独显示。
- 接触压力：离散点法向力除以其参考子三角面积，界面为表面加权平均。不是已收敛的Hertz接触峰值，不用于接触疲劳寿命结论。
- 轴端反力：包含电机/输出轴力矩，中间自由轴Z力矩应接近零。
- 仅验证有限元及离散接触方程，并不证明实物齿轮满足使用要求。刚性轴假设、固定法向、离散压力和未收敛网格是实质限制。

## 追溯与使用

`config.json` 保存不可变工况；`contact.json` 保存接触对、全部采样点、初始/最终间隙、力、压力和轴端结果；`fields.h5` 保存积分点应力、应变、真实位移及弹性位移；`gpu-execution.json`记录GPU库、设备、阶段和残差。`analysis.inp`是固定轴孔、施加最终接触力的**弹性参考问题**，可用CalculiX复核弹性位移/应力，不是接触独立求解输入。

本例已用CalculiX对照该弹性参考问题，详见 `GEAR_CPU_GPU_REFERENCE_CHECK.json`；该对照不独立验证接触搜索或压力峰值。普通任务日志不是Nsight时间线，不能据此声称已完成新的性能验收。

在“工况设置”中选择“齿轮接触传力”，分别编辑“组件材料”和“轴与接触”。已保存工况可用自然语言继续：

> 沿用当前三齿轮的材料、轴孔和接触条件，使用GPU，把小齿轮输入扭矩改为20 N·m，自动计算并与上一工况比较。保留教学假设及未验证项。
