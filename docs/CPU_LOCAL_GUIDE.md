# Strength Studio 0.5：本机使用说明

安装目录建议使用短路径，例如 `D:\strength-studio`，工作台地址为 http://127.0.0.1:8876 。服务仅监听本机地址。

## 启动、停止与诊断

- 双击 `Start.bat`：启动并打开工作台；已经运行时直接打开，不重复启动。
- 双击 `Stop.bat`：停止服务及它启动的计算进程。正在运行的任务会在下次启动时标记为“已中断”，已完成结果保留。
- 双击 `Diagnose-CPU.bat`：检查 Python、CPU 求解器、线程数、资源限制及 Codex 登录状态。
- 日志在 `.runtime\server.log`、`.runtime\server-error.log`。每项计算的配置、求解日志和结果在 `data\jobs\作业编号`。

本机已配置 Python 3.14.6 独立环境、CalculiX 2.23、项目专用 Node 24.19.0/npm、已构建前端。日常使用无需运行安装命令。

修改 `local-settings.json` 后重启生效：默认 6 个 CPU 线程、300000 自由度上限、600 秒 Codex 调用超时。仿真单作业串行排队，单次计算进程最多运行 1800 秒。实际网格超过限制时保留失败任务和原配置，不自动粗化网格或降低载荷。

已有工况的载荷对比、探针和网格修改可使用类型化增量规划：后端从任务保存的 `current_case` 完整继承材料、支撑、重力、附加载荷和粘结连接，只更新明确指定的面总力及数值/结果设置。未知、重名或重复更新的载荷会被拒绝；原工况和历史结果不改写。Codex 仍沿用本机登录、模型及推理设置，通过[官方非交互结构化输出接口](https://learn.chatgpt.com/docs/non-interactive-mode)调用。

规划超时不表示有限元求解失败。可在原会话中输入“重试上次任务”继承已补充条件；失败任务保留在历史中。`data/tasks/<任务编号>/planner/cli-status.json` 记录本次超时上限、输入大小、耗时与结束状态。三档收敛网格的尺寸为配置粗档尺寸、粗档/1.5、粗档/2.25；已有基准网格接近自由度上限时，应在规划阶段将细档设为该基准，不应先求解超限再悄悄降精度。

重新安装依赖和构建：在项目目录执行 `powershell -ExecutionPolicy Bypass -File Install.ps1 -DevBuild`。Windows Python 3.14 使用已验证依赖锁文件；CalculiX 下载按固定 SHA-256 校验，便携 Node 下载对照官方 SHASUMS256.txt。依赖和工具放在项目内。

## 从文字开始计算

1. 选择“内置支架”，或导入已有 STEP/STL。导入模型须是可用的三维实体几何；STL 的单位由导入选项确定。
2. 在材料窗口填写 E、泊松比、密度及来源。屈服强度可留空，但此时不会得出强度安全结论。内置演示钢材是教学假设值。
3. 助手连接选“Codex CLI”。它复用本机现有登录与模型配置，不需要另外配置 API Key。场景和几何摘要会交给 Codex，CAD 文件留在本机。
4. 输入明确的材料依据、支撑、载荷及作用位置。信息缺失时会集中补问；选面歧义时点击候选选区查看高亮，再补充回答。回答后自动继续。

可直接用于内置支架的指令：

> 使用已保存的演示钢材，固定四个安装孔的孔壁，在顶面沿全局 -Z 分别施加 1000 N 和 1500 N 总力，网格尺寸 8 mm，使用 CPU，比较应力、位移、安全系数和应变能，并生成报告。

继续输入：

> 把最后一个工况的力改成 2000 N，其他条件不变，只运行这个新工况并与前面比较。

> 查询上一工况最大位移节点处的总位移、位移向量和变形后坐标，不重新求解。

> 对当前 2000 N 工况做三档网格收敛分析，保留材料、约束、载荷与 8 mm 初始网格，使用 CPU。

每任务最多 12 个工况、3 档网格、3 轮结果反馈。解释的数值由后端通过作业/指标引用填入；解释失败与数值求解失败分开显示，已完成的数值结果和报告仍可下载。“本地规则（离线）”只适合明确参数的简单指令，不具备 Codex 的结果分析能力。

## 结果与报告

- 三维结果菜单按位移、应力、弹性应变、强度和能量分类，提供 39 个标量场。可调整变形倍率、网格、剖切及热点定位。
- 结果视图默认使用 1 倍真实位移。播放变形保持当前倍率；“自动放大”才采用建议倍率。可在数值框精确输入倍率，点击“真实比例”恢复 1 倍，点击“未变形”恢复原始外形。1 倍下实际变形可能很小；动画仅演示静态位移的往复显示，不代表振动或真实时间。
- PDF 封面后有中文目录，列明各节分析内容、探针/路径查询及可点击页码。目录不会把未评估项目或后续建议标成已完成仿真。
- “探针与完整结果”提供整体/组件/命名选区统计、点探针、直线路径、两点相对位移、反力矩与等效刚度查询。坐标在界面以 mm 输入。
- 点位移采用 C3D10 单元插值；应力路径是所属单元积分点后处理插值，可能跨单元不连续。模型外点留空，不吸附到模型表面。
- “工况设置 → 结果请求”可将探针、路径等随新工况保存，并加入该次报告。历史工况和结果不回写。
- 载荷—位移曲线：在多个工况中配置同一名称、相同探针、同一载荷及方向的“等效刚度与柔度”请求。只改变该载荷大小，其他材料、支撑、载荷保持一致，再打开“工况比较”。不同配置不连成同一曲线。
- PDF、CSV、VTU、HDF5 及完整计算包使用统一结果目录。HDF5 保留全部积分点原始应力/应变；CSV 极值与平均值使用 SI 单位，PDF 和界面按标注换算为 MPa/mm/%。

应力/应变统计采用原始积分点，平均值使用积分体积权重。选面应力统计表示相邻体单元，不是纯表面面积平均。平滑云图峰值可能与原始积分点峰值不同，两者均标注口径。

六分量顺序为 XX、YY、ZZ、XY、XZ、YZ。张量剪应变与工程剪应变分别提供，工程剪应变为张量值的两倍。旧 `strain` 字段仍表示最大绝对法向应变；等效弹性应变是独立字段。应变能积分包含两倍张量剪切项。

安全系数按 von Mises 或 Tresca 判据及所属组件屈服强度计算。安全裕度 = 安全系数 / 目标安全系数 − 1。零应力的安全系数、近零分母的三轴度或刚度返回无定义；缺少屈服强度不输出安全结论。反力矩同时保存参考点，整体反力按约束自由度去重。

## 首版适用范围

用于软件验证的三维实体、各向同性、小变形线弹性静力。支持已有 CAD、内置支架和标准算例；多组件可明确选择互不传力的独立计算。未增加文字生成 CAD、CPU 齿轮接触、通用摩擦接触、塑性、热应力、疲劳、屈曲、断裂、梁壳专用单元或复合材料分析。GPU 专属能力在本机显示不可用及原因。

解析解回归、平衡检查和收敛阈值用于确认软件数值行为，不等同于实际结构的工程认证。演示模型的理想固定边缘可能出现应力集中，局部峰值的解释须结合材料来源、支撑理想化和网格变化。
