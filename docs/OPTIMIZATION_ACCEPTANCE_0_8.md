## 主界面与原始数据

在现有主界面操作完成项目预览、比较页、接触隔离、内部表面裁剪、放大视图、真实时刻切换、仅报告导出及仅视频导出。浏览器检查未发现控制台错误。当前项目比较页纳入7项新旧研究，单位一致。

对研究 `04eace3ebae441b3b3b1d2988951c31f` 的第0、5、10帧逐项核对：真实时刻分别为0、300、600秒，温度、位移及位移模量与 HDF5 完全一致，接触压力投影与原始接触面计算一致，无映射区域返回缺失值。后续帧响应不重复包含网格拓扑。证据：`validation/optimization-live-frame-consistency.json`。

内部剖视裁剪已有显示表面，并不插值体内部的新截面场。显示应力/接触压力与原始积分点值分别标注；疲劳仍读取原始应力。旧磨损结果只有末值时，不补造逐帧历程。

## 性能与存储

在求解空闲时，经实际 HTTP 接口预热后各测10次，以最近秩法取P95：

| 接口 | P95 | 说明 |
|---|---:|---|
| 耦合范围元数据 | 0.034秒 | 目标≤0.5秒，通过 |
| 静力范围及支反力 | 0.036秒 | 新增持久化缓存，目标通过 |
| 结果索引 | 0.032秒 | 哈希绑定缓存 |
| 单变量温度帧 | 0.634秒 | 未压缩响应2,780,435字节；独立拓扑不会随帧重复 |

最终元数据记录：`validation/optimization-http-final.json`；温度帧测量记录：`validation/optimization-http-performance.json`。这些是本机测量，不据此承诺其他模型、硬件或负载下的耗时。支反力持久化缓存另有新进程读取验证，记录见 `validation/optimization-reaction-cache.json`。

只读清单快照：研究目录约237.17 GiB；全部数据约240.04 GiB，其中恢复必需127.92 GiB、待审阅诊断105.44 GiB、原件与证据3.84 GiB、可再生成产物2.83 GiB。测试缓存另约11.70 GiB。未删除历史文件。后续导出和安装会使实际总量增长；明细见 `validation/optimization-storage-inventory.json`。
