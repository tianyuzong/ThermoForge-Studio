# CPU 理想粘结装配

`LoadCase.assembly_mode = bonded` 使用 CalculiX 的线性多点约束，在独立的 C3D10 实体之间传递载荷。每个 `bonded_connections` 接口保存主/从组件、真实选面、匹配距离和连接假设。默认未配置接口；不会把导入的装配体自动粘成一体。

接口阻止分离、滑移和相对转动，适合软件验证或有依据的固定连接近似。它不是摩擦接触、滚动轴承、螺栓预紧或热膨胀模型。当前仅支持 `calculix_cpu`。

从面节点在指定距离内匹配主面相邻单元，使用该 C3D10 单元的体形函数建立位移约束。有限的微小间隙采用有界延拓，不移动节点；形函数满足刚体位移与力矩一致性。每个从节点只分配一个接口，主从图不能成环；从节点与固定自由度重叠时明确报错。每个实体连通分量必须经已映射接口获得六个刚体约束。

结果恢复沿连接层级消去从自由度内力，计算约束反力、自由自由度残差和逐接口合力/力矩。`bonding.json` 包含真实面、节点数、最大映射距离、接口力、关于全局原点的力矩、兼容误差和全部假设。报告与工作台均显示“整体理想粘结传力”；旧独立组件结果仍按原有口径读取。

验证包括真实 CalculiX 三段不同材料轴拉、弯曲与传力矩算例；缺失接口、循环连接、过大间隙和重复约束拒绝测试；仿射插值力矩一致性与不可变选面快照。CPU 结果平衡阈值仍为 1e-4。

复杂整机超出资源限制时，须先取得用户对几何简化的授权，明确保留的承载组件、完整传力路径、质量和力矩等效方式。原始 CAD、简化模型、来源映射、材料假设和求解记录保留在本机项目中。省略部件的细节强度与真实轴承接触不能由理想粘结结果推出；求解资源上限不会自动放宽。
