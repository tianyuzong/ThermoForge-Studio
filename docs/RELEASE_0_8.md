# ThermoForge Studio 0.8.0 发布说明

本次将本地统一平台封装为独立 Git 仓库。保留两个上游提交信息，不改变旧仓库远程地址，也不改写本机历史原始结果。

## 发布内容

- Windows 源码安装包：`Install.ps1`、`Start.bat`、`Stop.bat`，随包前端构建。
- 统一热、结构、高周疲劳、准静态周期接触、接触疲劳/磨损与热结构 CPU 工作流。
- 通用 Prompt、手动和 MCP 的同一套工况预检、草稿、计划和任务管理。
- 中文详细 README、英文入口、真实截图画廊与逐图来源。
- 实际生成的 42 页中文演示报告、1080p MP4 与动画预览。
- 固定依赖、源码和前端构建清单，ZIP 内逐文件哈希及压缩包外部校验。

## 分发边界

Git 不包含 `data/`、个人模型导入、凭证、`.venv`、`node_modules`、运行日志目录或第三方二进制运行库。示例 STEP、工况、报告与验证资料为显式选择的演示内容。

一份约 118 MB 的旧热致间隙诊断 `examples/reports/thermal-gap/audit.json` 仅保留在 Release 源码包中，避免成为超过 GitHub 单文件限制的 Git 对象。其哈希在 `REPOSITORY-CONTENTS.json` 与 Release 清单中记录；运行平台不依赖该文件。

源码包不是自包含 EXE。首次安装需网络、受支持 Python 与默认视频后端 Edge。CalculiX 由安装器从官方固定地址下载并校验。CPU 验收环境为 Windows x64 / Python 3.14；其他环境和 GPU 未纳入本轮重新验收。

## 证据与内容来源

本次文档封装复用已经完成的实际结果，没有为截图重新启动大型仿真。截图分为实时 UI 截图、平台视频导出帧、平台 PDF 页面渲染。每项在画廊注明，未生成或伪造物理结果。

报告有目录、无附录，使用平台原始场与工况快照生成。演示材料与验证状态保留原文，不因公开发布变成实测或认证数据。旧失败、取消及证据不足的状态不被包装成通过。

具体回归结果见 `OPTIMIZATION_ACCEPTANCE_0_8.md`。文档发布检查与安装源码包的哈希单独提供，不能替代该物理分析的数值验收。
