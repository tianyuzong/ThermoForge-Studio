# 电机案例可视化素材

> 本目录是插件分支保存的历史单端载荷素材，不是双端各1000 N案例。历史P点和收敛值只属于其原始模型；双端模型的P=(-155,0,0) mm在孔内，结果无定义。新展示与证据见[双端案例](../../../examples/motor-double/README.md)。
>
> Archived single-end load assets, separate from the two-end case. Historical P-point and convergence values apply only to their original model. P is in the bore and undefined in the two-end model.

采集日期：2026-09-28。应用版本 0.5.0，报告版本 2.7。全部画面来自本机实际工作台及已生成报告，无合成模型或虚构数值。

## 案例及结果来源

- 模型：158 实体原装配经授权简化为 10 个等效组件，保留轴、轴承等效环、端盖、机壳、底脚间传力；停机理想粘结。
- 求解：CalculiX CPU，6 线程，细档 94,239 节点、51,137 个 C3D10 单元、282,717 自由度。
- 1000 N 作业：`302177f3c6294db8846dbbf2727ce011`；1500 N：`9b2ebd458b004215af50fee0f3000347`；2000 N：`cdc381b99efa4be8b446a8652e3092ba`。
- 同批任务：`7dfff07cbb0843219e4243a587230337`。这些编号仅用于已有本地结果追溯，不要求其他安装具备这些数据。
- 载荷：固定两侧底脚，轴端沿 −Z 总力，加等效自重及附件质量凝聚载荷；比较只改变轴端径向力。
- 材料：试算等效参数；未提供屈服强度，不输出强度合格结论。
- 1000 N 原始积分点峰值 39.0031917 MPa；最大总位移 0.03787318 mm。节点显示场与原始积分点极值可以不同。

## 阅读边界

三档网格为 27 / 18 / 12 mm。收敛判据使用总位移和组件 8、面 209 相邻体单元的原始积分点应力；最后两档变化约 0.470% / 2.339%。全局应力峰值和总能量另列，不由这两个判据推断已收敛。

理想粘结没有真实轴承滚动、接口分离、摩擦或螺栓预紧。被移除细节的局部应力不在评价范围。材料来源和完整物理条件仍应在实际报告中核对。
