# 加工前热评估

通过 Agent 对话配置热工况、材料、支撑和设计限值，在加工前计算温度分布、热变形及热应力。温度场先求解，随后将各保存时刻的温度作为三维准静态热弹性载荷。配置经校验后由用户确认运行。

## 支持的分析与参数

- 热分析：原有稳态或瞬态固体导热、给定对流系数及辐射。`environment_only=true` 允许无内部热源的环境加热或冷却，必须有换热边界；普通热源算例仍要求有效热源。
- 材料力学参数：`young_modulus_Pa`（Pa）、`poisson_ratio`、`thermal_expansion_CTE_per_K`（1/K）。不能从“铝”或“不锈钢”名称推断真实牌号的弹性及强度参数。缺少弹性模量或泊松比时阻止结构求解。
- `structural.mode=free`：各独立体分别消除六个刚体运动自由度，不施加虚构固定点。
- `structural.mode=constrained`：通过 `supports` 指定固定面及 `axes`（x、y、z、xy、xz、yz、xyz）。面选区由 Agent 的 `surface_selection` 映射，不能让语言模型猜三角面编号。网格中每个独立体必须得到充分支撑，否则返回明确错误。
- `structural.reference_C`：无应力参考温度，与热分析初始温度是不同物理量，可单独设置。
- `design_limits`：允许最低/最高温度、最大位移（m）、强度安全系数（默认1.5）。材料 `yield_strength_Pa` 为屈服强度，允许等效应力为屈服强度/安全系数。

## 可直接输入 Agent 的示例

以下为功能演示参数，不是某个材料牌号的认证数据；工件实际固定位置和材料参数应按设计输入。

> 使用当前模型。纯环境温变工况，无热源。基础材料使用不锈钢，弹性模量200GPa，泊松比0.3，屈服强度205MPa，线膨胀系数17.3ppm/K。初始温度25摄氏度，环境温度85摄氏度，默认换热系数10，关闭辐射。启用热应力分析，底面固定，无应力参考温度25摄氏度。允许最低温度负45摄氏度，允许最高温度80摄氏度，允许最大位移0.1mm，强度安全系数1.5。采用瞬态，仿真总时长1200秒，计算步长2秒，每30秒保存，网格尺寸4mm。请生成草案并等待确认。

低温工况在新的对话草案中将环境温度改为负40摄氏度，其余条件保持不变，再单独计算。恒定环境的热浸泡必须运行足够长时间或采用满足适用条件的稳态分析；短时未超限不能证明长期可靠。

已有内部热源工况可保留热源并追加：

> 保留当前热源和热边界。基础材料弹性模量200GPa，泊松比0.3，屈服强度205MPa，线膨胀系数17.3ppm/K。启用热应力分析，底面固定，无应力参考温度25摄氏度。允许最高温度80摄氏度，允许最低温度负45摄氏度，允许最大位移0.1mm，强度安全系数1.5。重新校验并生成草案。

修改固定方向用“底面固定z方向”，切换自由体用“改为自由热弹性状态”。只固定一个方向通常无法约束全部刚体运动；应按真实支撑追加其他面/方向，不能为了通过校验虚构夹持。

## 结果与风险判定

界面可切换温度、热位移（mm）和 von Mises 等效应力（MPa），按时间播放，并设置变形显示倍率。倍率只影响画面；设计限值检查使用真实计算值。内部剖切目前显示温度，完整结构场可在 ParaView 中查看。

`assessment.json` 和报告逐项给出数值、限值、发生时间、位置和状态。未给限值/屈服强度的检查显示“未评估”；未启用结构求解时不会用自由膨胀估算通过位移或强度检查。“在已设限值内”只陈述当前模型和已设置标准的计算结果，不能称为产品安全认证。

`stress.bin` 是每帧每单元的六个应力分量，顺序 xx、yy、zz、xy、yz、xz，单位Pa，float32小端。`displacement.bin` 是每帧每有限元节点的XYZ位移，单位m。浏览器使用另行投影到显示网格的数据；表面统计可能与原始体网格峰值不同，评估使用原始体网格。

ZIP内 `temperature.xdmf` + `thermal-fields.h5` 提供温度、节点位移、单元等效应力和六个独立应力分量。报告包含无应力温度、材料力学参数、支撑映射面积、平衡残差、主应力极值及设计限值结果。检查位置保存在评估JSON中。

## 数值模型和边界

结构离散采用P1四面体，使用 `epsilon = B u` 和 `sigma = D (epsilon - alpha (T-Tref) I)`，热载荷按单元温度场积分，求解稀疏平衡方程。每帧复用结构刚度分解。von Mises来自单元应力；主应力极值包含单元内线性温度产生的静水应力变化。

适用范围为常物性各向同性、小应变、小变形、准静态线弹性；不包含机械接触、螺栓预紧、外部机械载荷、塑性、蠕变、断裂、疲劳寿命或CFD。共享节点视为机械粘结，未连通实体之间不传递机械力；空气间隙热耦合不会自动生成结构连接。相变材料不能启用此结构模型。总应变或热应变超过1%会标记超出小变形验证范围。

屈服判据针对提供屈服强度的延性材料，不代表脆性材料断裂、静水压力破坏或循环寿命判定。固定边缘与尖角的应力可能具有网格依赖，不能只依据单个最大应力值判定实际失效。

结构计算最多90000自由度，并检查帧数×单元数的结果规模；超过限制会明确拒绝，不自动改变用户的网格、时间步长或保存间隔。

## 验证证据与交付前复核

- `tests/test_thermoelastic.py`：均匀升温/降温的自由膨胀解析解、完全约束静水应力解析解、轴向约束杆解析解、独立scikit-fem刚度对照、多个独立体、异材同CTE、欠约束拒绝、限值缺失及大应变标记。
- `tests/test_agent_structural.py`：Agent材料单位、环境工况、固定面/方向、对话补参、Codex语义选区编译及作用域保持。
- `tests/test_engineering_pipeline.py`：高低温环境下从Agent配置到温度、位移、应力、PDF/CSV/ZIP的完整流程。
- `tests/test_engineering_ui.cjs`：结果场及单位切换、变形显示倍率、旧结果兼容。`tests/test_agent_ui.cjs`验证草案确认与环境工况入口。

工程使用需比较网格与时间步长、核查支撑映射与材料分配，并以热电偶/红外等实测数据验证关键温度。解析解和软件集成测试验证的是实现，不替代实物验证，也不能量化承诺减少多少样机或缩短多少周期。
