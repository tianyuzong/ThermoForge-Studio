# ThermoForge Studio 示例

从工作台首页的示例菜单导入模型。`case.json` 是默认工况，其他 JSON 文件是可复制的研究配置；请保留文件内的材料来源和假设。各示例的数值验收见根目录 `VALIDATION.md`，便携报告位于 `reports/`。

| 目录 | 内容 |
|---|---|
| `motor-unified/` | 十组件电机、原静力回归、轴疲劳、稳态／瞬态热、装配热应力与轴承座双向接触 |
| `local-bearing/` | 独立滚动体—滚道、完整往复周期、滚动接触疲劳与滑移磨损、129 帧步长复算 |
| `thermal-gap/` | 10 μm 初始间隙的热致闭合、升温后冷却分离、显式时间步细化 |
| `gears/` | 20:20 渐开线齿轮及自由从动轴啮合；具体通过范围见验收记录 |
| `reports/` | 中文 PDF、不可变工况、结果摘要和原始场校验值 |

滚动体与齿轮采用 E=2 GPa 的数值演示材料，不能据此评价真实钢制轴承或齿轮寿命。电机演示疲劳曲线也不是该电机的实测数据。

## 上游 L 形安装支架演示

`l-bracket.step` 为本项目生成的演示 CAD：100 × 60 × 60 mm，壁厚 8 mm，根部 R6 圆角，4 个直径 8 mm 安装孔。CAD 长度单位为米，导入后 UI 显示毫米。

`material.json` 明确记录假设物性与来源。`cases.json` 是实际 Codex CLI 规划、宿主验证后绑定面编号的四个完整工况；`agent-plan.json` 保存原始自然语言指令。选区面编号对应这份 CAD 的几何证据，换模型后不可沿用。

四个工况共用 5 mm 目标网格、38,508 个节点、22,929 个 C3D10 单元。孔壁全部固定，顶面为竖板顶部窄面，面积 480 mm²。

| 工况 | 总力 N（X/Y/Z） | 最大 von Mises / MPa | 最大位移 / mm | 最小屈服安全系数 |
|---|---|---:|---:|---:|
| 1 竖向 | 0 / 0 / −1000 | 69.4568 | 0.0216291 | 3.3834 |
| 2 竖向比较 | 0 / 0 / −1500 | 104.1852 | 0.0324436 | 2.2556 |
| 3 侧向 | 0 / 300 / 0 | 32.3820 | 0.00784793 | 7.2571 |
| 4 组合 | 0 / 300 / −1000 | 97.6280 | 0.0260223 | 2.4071 |

这些是实际 CPU 计算结果，非预置演示值。演示未请求网格收敛，不能把表中应力峰值视为经收敛验证的实际承载能力。

各 `case-*` 目录包含中文报告、指标 CSV、计算配置和完整数值摘要。完整 HDF5/VTU/INP/DAT/日志在本机工作台相应结果的“完整计算包”中。`validation-metrics.json` 是另行执行的解析解验证记录。
